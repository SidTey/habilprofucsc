R1. Carga automática de datos desde sistemas UCSC

Entradas: Rut_Alumno, Nombre_Alumno, Correo_Alumno, Rut_Profesor, Nombre_Profesor, Correo_Profesor, Fecha_Ingreso, Nota_Final, Fecha nota.

Requisitos de la función: 
R1.1 El campo Rut_Alumno es un número entero con rango [1000000, 60000000], El tamaño mínimo y máximo para este campo es de 7 y 8, respectivamente.
R1.2 El campo Nombre_Alumno es un string con un máximo de 100 caracteres, compuesto de caracteres del abecedario (a-z , A-Z), incluyendo tildes.
R1.3 El campo Correo_Alumno debe aceptar caracteres alfanuméricos (Incluyendo “@” y “.”) de una longitud entre [1,255].
R1.4 El campo Rut_Profesor es un número entero con rango [10000000, 60000000], El tamaño mínimo y máximo para este campo es de 7 y 8, respectivamente.
R1.5 El campo Nombre_Profesor es un string con un máximo de 100 caracteres, compuesto de caracteres del abecedario (a-z , A-Z), incluyendo tildes.
R1.6 El campo Correo_Profesor debe aceptar caracteres alfanuméricos (Incluyendo “@” y “.”) de una longitud entre [7,255].
R1.7 El campo Fecha_Ingreso es un dato tipo Date de tamaño 10, con un formato de DD/MM/AAAA, donde DD, MM y AAAA son entero de [01,31], [01,12], [2025, 2050], respectivamente.
R1.8 El campo Nota_Final es un dato tipo Float de tamaño 3, entre [1.00, 7.00] (Ejemplo: 6.56, 7.00, 3.43), este dato puede ser nulo.
R1.9 El campo Fecha_nota es un dato tipo Date de tamaño 10, con un formato de DD/MM/AAAA, donde DD, MM y AAAA son entero de [01,31], [01,12], [2025, 2050], respectivamente.
R1.10 Los requisitos anteriores son obligatorios para la carga de datos, excepto R1.9 y R1.8 que es opcional.
R1.11 Para cada campo, el sistema “Habilprof” se debe rescatar los datos del alumno (Rut_Alumno, Nombre_Alumno, Correo_Alumno) desde el módulo alumnos ucsc y de los profesores (Rut_Profesor, Nombre_Profesor y Correo_Profesor) desde el módulo profesores ucsc. A excepción de Nota_Final y Fecha_Nota.
R1.11.1 Para Nota_Final el sistema “Habilprof” debe rescatar el dato desde el módulo notas en línea ucsc, solo si existe, si no es así Nota_Final tomará valor NULL.
R1.11.2 Para Fecha_nota, se mantendrá el valor NULL por defecto, se tomará el valor de la fecha del sistema “Habilprof” al momento de registrar Nota_final en el sistema “Notas en línea de la UCSC”.
R1.12 Se debe verificar que los datos del alumno (Rut_Alumno, Nombre_Alumno, Correo_Alumno y Nota_Final) y de los profesores (Rut_Profesor, Nombre_Profesor y Correo_Profesor) estan registrados en el sistema “Habilprof”.
R1.12.1 De encontrar datos de alumno o profesor no registrados en el sistema de “HabilProf” debe cargarlos y actualizarlos de forma automática según R1.11.
R1.13 Se registra un log del sistema “Habilprof” con los datos (Rut_Alumno, Nombre_Alumno, Correo_Alumno, Nota_Final, Rut_Profesor, Nombre_Profesor y Correo_Profesor).
R1.15 En caso de fallo de conexión con el sistema UCSC, se desplegará el mensaje: “No se ha podido establecer conexión con los sistemas UCSC”.
R1.16 Este proceso se activará automáticamente cada minuto.

Salidas: 
Salida 1: Rut_Alumno,Nombre_Alumno,Correo_Alumno, Rut_Profesor, Nombre_Profesor, Correo_Profesor, Fecha_Ingreso, Nota_Final.
Salida 2: Despliegue de mensajes en R1.15
